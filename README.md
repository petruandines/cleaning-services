# Petru & Inés — site static

Site HTML/CSS/JavaScript pregătit pentru GitHub Pages în repository-ul `cleaning-services`.

## Publicare
Copiază conținutul acestui folder în rădăcina repository-ului, fără să ștergi folderul existent `catalog/`. Pagina principală este `index.html`.

## Imagini de înlocuit
Imaginile temporare sunt în `assets/img/placeholders/`. Păstrează numele fișierelor pentru a înlocui rapid fără modificări HTML sau schimbă `src` în paginile dorite.

## Contact
Telefonul, WhatsApp, programul, Facebook, profilul Google și catalogul sunt deja integrate. Formularul deschide WhatsApp cu un mesaj precompletat; utilizatorul confirmă trimiterea în WhatsApp.

## SEO
Sunt incluse: title/description unice, canonical, Open Graph, JSON-LD LocalBusiness/Service/BreadcrumbList, `robots.txt`, `sitemap.xml`, URL-uri curate și pagini dedicate serviciilor.
