# GA4 privacy-first — implementation and release gate

GTM-T5W2QNNZ → G-9FBR322D7B. The container is the existing published Google tag; do not add a second GA tag. The Cloudflare build injects a deferred local script only into indexable canonical public sitemap pages. New public pages must have a matching canonical and be listed in sitemap.xml. The policy page is included. Private portal, catalog and other excluded routes are not instrumented. No noscript iframe.

Consent is stored locally for 180 days. Before analytics consent the Google container does not load. Advertising consent always stays denied. On withdrawal disable GA, update consent, remove accessible GA cookies, reload. Internal opt-out per browser: in DevTools Console run window.PIAnalytics.setInternal(true); to restore use window.PIAnalytics.setInternal(false). Do not share or filter IPs. Unknown URL query parameters and unrecognized fragments fail closed; allowlisted attribution values only. Marketing UTM content uses fixed placement labels or numbered codes (e.g. postare_01), and campaigns use the existing offer slugs, Romanian month/year or campaign_N codes. Never put personal data in these codes. A single fbclid is discarded locally via history.replaceState before the tag can load; if cleanup fails, no measurement. Duplicate parameters and arbitrary values are rejected. Referrer is sanitized; private internal referrers block analytics. URL parameters and cross-origin referrers still require network verification.

Events: whatsapp_click, phone_click, quote_request_start (validated form handoff only, not successful message), offer_view, pricing_view, service_view, language_switch. No generate_lead until a real request can be verified. GA4 events are sent using gtag event to the existing destination; verify delivery before marking contact events as key events. The static policy is a proposed disclosure for public-site analytics, not legal certification; verify processor arrangements, retention of enquiries and other tools (including portal) separately before acknowledgment.

## Release gate
- Run node --test scripts/analytics-privacy.test.mjs and node scripts/build-cloudflare.mjs on a checkout.
- Browser test on deployment preview: fresh profile, no GTM/GA requests or GA cookies before decision and after reject. Accept: exactly one container, verify page_view and custom events in Tag Assistant and Realtime; check four consent signals, ads all denied. Withdraw: reload and check no further measurement. Reload after accept/reject, mobile layout, keyboard focus, browser without storage, staff exclusion.
- Verify no analytics script/network on /portal/, /portal/project/ (use only fake token), private referrers, unknown query parameters, external preview domains. Inspect actual GA payloads for URL, referrer, title, PII; test cross-origin attribution with safe ChatGPT UTM.
- Verify public navigation, all validated form handoffs and offer calculators remain functional. Confirm Search Console & Business Profile links, mark verified whatsapp_click and phone_click as key events (not a confirmed customer). Do not acknowledge data collection until disclosure and consent mechanism verified.
